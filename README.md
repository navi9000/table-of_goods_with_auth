# О проекте

Тестовое задание на позицию фронтенд-разработчика. Проект включает 2 страницы: страницу авторизации и страницу с таблицей товаров.

## Стек

Core: React, Typescript, CSS modules
Libraries: react-router, tanstack table, zod
Infrastructure: Vite, Eslint
Architecture: FSD

## Особенности проекта

- Авторизация с помощью access и refresh токенов
- Таблица товаров с поиском, пагинацией
- Для архитектуры использован паттерн FSD
